# LUNQRA

ATEM's Human Intent Network: “Say what you need. Find who or what can make it happen.”

The primary loop is intent → understanding → matching → connection → conversation →
outcome → reputation. Posts and marketplace discovery support this loop.

V0 acceptance: a user signs up, completes a persisted profile, describes a need naturally,
confirms parsed fields, publishes an intent, receives persisted ranked candidates with
honest heuristic explanations, opens a profile and exchanges realtime messages with the
other participant. The intent can be marked complete. Raw text is always preserved.

Phase 0 supplies infrastructure only. No active network, account creation, matching or
messaging is advertised as functional before the corresponding phase is verified.
